## 2. 미구현 또는 명확하지 않아 구현이 막힌 항목

스펙·재현·우선순위가 없어 **현재 “완료”로 닫기 어렵거나**, **요구가 질문 형태**로만 있는 것들입니다.

| ID | 상태 | 사유 |
|----|------|------|
| **1-1** | 부분/불완 | “Method” 정의·알람별 사운드 범위 없음. (채널/ID 등 **일부 기술적 개선**은 스펙 없이도 시도 가능하나, 검수 통과 기준 불명확.) |
| **1-3** | 재현·원인 불명 | Quiet hours + 끊김 시 **앱 종료** — 재현·스택 없으면 수정 검증 불가. |
| **1-5** | 미구현 | 한국어 선택·리소스 범위·기본 언어 미확정. |
| **1-6** | 미구현 | 15일 만료 시 **앱主도 연결 해제** + 만료 전용 플로우 — 만료 시각·정리 범위·화면 순서 미확정. |
| **2-2** | 체크리스트 성격 | 한 줄에 요구·관측 혼재 → **기대 동작 문서**로 먼저 정리 필요. |
| **2-3** | 미구현·참조 불충분 | 이미지·OK 조건 없이 UI 동일 구현 어려움. |
| **2-1** | 일부만 명확 | 자동업로드 성공 정의, 재설치 풀 복구, Remember Me — **요구 vs 질문** 구분 필요. |
| **1-7 (2·3)** | 부분 진행 가능 | (1) SN 변경·시작일 등은 일부 로직 반영 가능. **오프라인 가입 후 메타 불일치**, **Disconnect vs 자동 재연결**은 시나리오·재현에 따라 추가 작업. |
