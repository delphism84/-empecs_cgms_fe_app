1. App 동작관련 
1-1. 사운드 알람 미동작 문제
• Very Low, Low, High, Rapid Change, Signal Loss 알람 발생 시 사운드 알람이 동작하지 않습니다.
• Method 설정 값이 저장 후에도 반영되지 않는 것으로 추정.
1-2. Signal Loss 알람 주기 미반영 문제
• Signal Loss Repeat 설정에서 1min, 5min 등으로 알람 주기를 변경 후 저장해도, 알람이 최초 1회만 발생하고 이후에는 반복되
지 않습니다.
• 알람 주기 설정 값이 정상적으로 적용되지 않는 것으로 추정.
1-3. Quiet hours 시간 저장 후 앱 동작 간 문제
• Signal Loss Quiet Hours 시간을 설정 후, 해당 시간이 되었을 때 센서 신호가 끊기면 앱이 종료되며, 다시 실행 시 로그인 화면
으로 이동.
• Quiet Hours를 설정하여도 App이 종료되는 현상이 발생되어서는 안됨
1-4. Lock screen banner 표시 형식 수정 요청
• 초기 제안된 형태: 혈당 변화 화살표 + 최신 혈당 값 동시 표시
• 현재 구현 상태: “Last Reading” 알림 형식으로만 표시됨.
• 요청사항: 이전 제안된 형식(혈당 값 + 변화 방향 화살표)으로 수정 필요.
