소셜 로그인(Google, Apple, Kakao) 잔여 작업 현황

현재 Flutter 앱 내의 소셜 로그인 연동(SDK 호출 및 토큰 획득)은 구현되어 있으나, 백엔드 검증 및 프로덕션 환경 설정에 중요한 잔여 작업이 남아있습니다.

완료됨 1. Flutter 앱 (FE) 연동

  • SDK 연동: Google(google_sign_in), Apple(sign_in_with_apple), Kakao(kakao_flutter_sdk_user) 패키지 설치 및 로그인 호출 로직 구현 완료 (SocialAuthService).
  • 키 설정: social_auth_config.dart, AndroidManifest.xml, Info.plist에 클라이언트 ID 및 네이티브 앱 키 하드코딩 완료.
  • 토큰 전달 플로우: 각 플랫폼에서 발급받은 idToken 또는 accessToken을 백엔드 API (POST /api/auth/social/verify)로 전송하여 앱 전용 JWT를 발급받는 통신 흐름 구현 완료.

필요함 2. 백엔드 (BE) API 구현 및 배포

가장 핵심적인 블로커(Blocker)입니다. 현재 백엔드 코드(backend/src/routes/auth.js)에는 일반 이메일 로그인(/login, /register)만 존재합니다.

  • 라우트 추가: POST /api/auth/social/verify 엔드포인트 개발.
  • 토큰 검증 로직:
    • Google: 전달받은 idToken을 Google OAuth2 라이브러리(예: google-auth-library)로 검증.
    • Kakao: 전달받은 accessToken을 사용해 Kakao API (https://kapi.kakao.com/v2/user/me) 호출 및 유효성 검증.
    • Apple: 전달받은 idToken을 Apple 공개 키(JWKS)로 서명 검증.
  • 유저 매핑 및 JWT 발급: 소셜 로그인 정보(이메일 등)로 DB에서 유저를 찾거나 새로 생성(Upsert)한 뒤, 기존 이메일 로그인과 동일한 규격의 자체 JWT(토큰)를 응답으로 내려주어야 합니다.
  • 서버 배포: 개발 완료 후 운영 서버(https://empecs.lunarsystem.co.kr)에 반영해야 앱에서 정상 로그인이 가능합니다.

필요함 3. 소셜 플랫폼 콘솔 설정 (운영/고객 측)

앱이 실제 릴리즈(스토어 등록) 및 배포될 때 반드시 맞춰야 하는 설정들입니다.

  • Google Cloud Console:
    • 현재 소스에는 Web 클라이언트 ID가 Android 설정에 하드코딩되어 있습니다.
    • 실제 릴리즈 시에는 Android용 OAuth 클라이언트 ID (패키지명 + 릴리즈 키스토어 SHA-1 해시)와 iOS용 클라이언트 ID를 별도로 생성하고 앱 설정에 반영해야 구글 로그인 에러(예: DEVELOPER_ERROR)가 발생하지 않습니다.
  • Kakao Developers:
    • [내 애플리케이션] > [플랫폼] 설정에 Android 패키지명(com.helpcare.app) 및 실제 릴리즈 키 해시 등록.
    • iOS 번들 ID 등록.
  • Apple Developer (iOS):
    • Apple Developer 포털에서 App ID에 Sign In with Apple Capability 활성화.
    • Xcode 프로젝트(ios/Runner.xcworkspace)에서 Signing & Capabilities에 'Sign in with Apple' 추가 (현재 레포지토리에 .entitlements 파일이 없는 것으로 보임).

권장 4. 기타 개선 사항

  • Kakao 로그인 폴백: 현재 코드는 loginWithKakaoTalk()(카카오톡 앱으로 로그인)만 시도합니다. 카카오톡이 설치되어 있지 않은 기기를 위해 실패 시 loginWithKakaoAccount()(웹뷰 로그인)로 폴백(Fallback)하는 로직 추가를 권장합니다.
  • 보안: 소셜 키(클라이언트 ID 등)를 코드에 하드코딩하는 대신, 환경 변수(.env 또는 --dart-define)로 관리하는 것이 보안 및 유지보수에 좋습니다.
